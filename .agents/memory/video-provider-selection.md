name: Video provider selection
description: The user's preference for choosing animation providers by video type.
---

Choose the video provider according to the kind of video the user wants to generate, rather than requiring one fixed provider for all videos.

**Why:** The user said, “Any one depending on the kind of video the user wants to generate.”

**How to apply:** Evaluate each provider's supported input modes, output settings, safety terms, and availability before recommending or implementing a routing rule. Do not silently switch providers after a request has been submitted.
