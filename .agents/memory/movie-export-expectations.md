The user chose storyboard movies now, in both landscape and portrait and both 720p and 1080p.

**Why:** The user explicitly selected this format rather than waiting for finished animated clips for every shot.

**How to apply:** Keep full-episode and single-series MP4 exports available. Clearly label storyboard movies as review animatics, not finished character animation or recorded dialogue. A short real-video validation clip must not be presented as a finished episode.

Four-format batch progress means queue acceptance, not successful rendering or series ZIP packing. Retrying missing formats must preserve each original creation intent; an older movie with the same orientation and resolution is not proof that this batch's request succeeded.

**Why:** Creators can intentionally build the same formats more than once, and a lost queue response can hide an accepted job. Treating matching formats as equivalent either skips wanted work or duplicates a prior request.

**How to apply:** Reconcile exact request identities and original targets. A failed or cancelled accepted job remains an acknowledged batch entry; rebuilding it is a separate explicit action.
